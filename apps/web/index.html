mizan

Every badge mizan shows is computed by strict normalised containment against a committed corpus, not asserted by a model. The three lines below are the only verdicts the verifier can emit; there is no fourth state and no default badge.

transcript PRECOMPUTED (deterministic replay) the answers and quotations are replayed from a committed transcript; every badge below was computed by the verifier against the committed corpus on this run, live or replayed alike.

The three badges

  • VERIFIED the quoted span is contained in the record the claim cites, after deterministic folding.
  • UNVERIFIABLE mizan cannot decide: no citation, an unresolvable identifier, an empty quote, a paraphrase, a timeout or malformed model output.
  • REJECTED the citation resolved to a real record and that record does not contain the quote.

This page makes no request, and takes no input

No script, no stylesheet link, no image, no font, no fetch. It renders from file:// with zero network access, so what you are reading is the committed bytes and nothing else. There is no text box on purpose: accepting input needs a script, and ADR-C3 forbids one. To ask a question, use the CLI — bun run ask, with a key set for a live run and unset for the labelled replay; bun run demo prints the full report, with each source’s URL and the snapshot hash beside every badge.
